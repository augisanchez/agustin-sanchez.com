Privacy policy

Agustin Sanchez Reference Boards. Last updated November 5, 2026.

This is a personal tool. I use it to read my own Pinterest account through the Pinterest API. It is not a public product and has no other users.

Data accessed

With my authorization, the tool uses read-only permissions (user_accounts:read, boards:read, pins:read) to read my own profile and account information, boards, and pins. It does not create, edit, publish, or delete content, and it does not access any other user’s data.

How data is used

The data is used only to browse and reference my own boards and pins for personal design work.

Storage and sharing

Access tokens are stored only on my computer. Pinterest data is not sold, shared, or sent to third parties. The tool has no analytics or tracking.

Revoking access

Access can be revoked at any time in Pinterest under Settings, Security and permissions, Apps.
